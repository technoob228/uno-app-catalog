# Uno App Catalog — compose-планы приложений App Store

Каждая папка `apps/<id>/` — готовый к `docker compose up -d` план одного
приложения из каталога Uno (fishcode `internal/apps/templates.yaml`).
Каталог ссылается на **конкретный коммит** этого репозитория, поэтому правка
здесь ничего не меняет у клиентов, пока каталог не переедет на новый коммит.

Контракт с установщиком (uno-box-agent):

- агент клонирует репозиторий, чекаутит закреплённый коммит и запускает
  `docker compose -f apps/<id>/compose.yaml up -d --build`;
- переменные приходят окружением процесса `docker compose`:
  - системные (их ставит control plane): `UNO_APP_URL`
    (`https://<app>-<машина>.app.uno4.dev`), `UNO_APP_HOST` (то же без схемы),
    `UNO_BOX_HOST` (имя машины), `UNO_PORT_<порт>_<TCP|UDP>` (внешний номер
    дополнительного порта);
  - заданные человеком при установке (email, пароль, выбор хранилища) и
    сгенерированные секреты — имена см. в каталоге;
- веб-вход приложения — один порт на машине (`web_port` каталога), за ним
  HTTPS-прокси ноды (TLS, `X-Forwarded-Proto: https`, WebSocket, тело до 100 МБ).

Данные — только в именованных volume'ах (или в `/home/unowork/...`, чтобы
файлы были видны в «Файлах» Uno Work) — они переживают перезапуск и
переустановку.

Лицензия файлов этого репозитория — MIT. Сами приложения — под своими
лицензиями (см. `description` в каталоге и README каждого проекта).
